## 1. 项目概述

### 1.1 项目愿景

Ivan_HappyWoods 是一个**现代化的 AI 对话系统**，旨在提供温暖、自然、智能的人机交互体验。通过优雅的设计语言和流畅的动画效果，让 AI 对话不再冰冷，而是充满人性化的温度。

### 1.2 核心价值主张

- 🎨 **温暖视觉** - 琥珀色主题，自然曲线，舒适的视觉体验
- 🤖 **智能对话** - 流式响应，Markdown 渲染，代码高亮
- 🌓 **完美深色模式** - 无闪烁切换，WCAG AAA 标准
- 🎬 **流畅动画** - 60fps 性能，spring 弹性曲线
- ♿ **无障碍支持** - 键盘导航，屏幕阅读器，ARIA 标签

### 1.3 目标用户

| 用户类型 | 特征 | 需求 |
|---------|------|------|
| **个人用户** | 日常使用 AI 助手 | 简单易用，响应快速 |
| **开发者** | 需要技术支持和代码帮助 | 代码高亮，语法支持 |
| **内容创作者** | 写作、翻译、创意 | Markdown 渲染，导出功能 |
| **企业用户** | 客服、知识管理 | 多会话管理，历史记录 |

### 1.4 技术栈

| 分类 | 技术 | 版本 | 用途 |
|------|------|------|------|
| **框架** | Next.js | 15.5.5 | React 全栈框架 |
| **UI 库** | React | 19.1.0 | 用户界面构建 |
| **语言** | TypeScript | 5.3+ | 类型安全 |
| **样式** | TailwindCSS | 4.x | 原子化 CSS |
| **动画** | Framer Motion | 11.18.2 | 流畅动画 |
| **状态** | Zustand | 5.0.8 | 轻量级状态管理 |
| **主题** | next-themes | 0.4.6 | 深色模式切换 |
| **工具** | CVA | 0.7.1 | 变体管理 |

## 2. 功能需求

### 2.1 AI 对话功能 (FR-001)

#### 2.1.1 流式响应 (FR-001-001)
- **描述**: 用户发送消息后，AI 响应以流式方式实时显示
- **优先级**: P0（必须）
- **依赖**: 后端 SSE 接口
- **验收标准**:
  - 支持 Server-Sent Events (SSE) 协议
  - 响应内容逐字显示，无延迟感
  - 支持中断和取消流式响应
  - 错误时显示友好的错误提示

#### 2.1.2 Markdown 渲染 (FR-001-002)
- **描述**: AI 响应支持 Markdown 格式，包括标题、列表、代码块等
- **优先级**: P0（必须）
- **依赖**: react-markdown, remark-gfm
- **支持语法**:
  - 标题（H1-H6）
  - 列表（有序/无序）
  - 代码块（带语法高亮）
  - 粗体/斜体/删除线
  - 链接和图片
  - 表格
  - 引用块
- **验收标准**:
  - 正确渲染所有 Markdown 语法
  - 代码块支持语法高亮
  - 代码块显示语言标签
  - 样式与设计系统一致

#### 2.1.3 消息输入 (FR-001-003)
- **描述**: 用户可以通过输入框发送文本消息
- **优先级**: P0（必须）
- **功能点**:
  - 多行文本输入
  - 自动高度调整（最大 5 行）
  - Enter 发送，Shift+Enter 换行
  - 支持粘贴文本
  - 输入时显示字符计数
- **验收标准**:
  - 输入框高度自适应内容
  - 快捷键正常工作
  - 粘贴保留格式
  - 空消息不可发送

#### 2.1.4 消息历史 (FR-001-004)
- **描述**: 显示当前会话的所有历史消息
- **优先级**: P0（必须）
- **功能点**:
  - 按时间顺序显示
  - 区分用户消息和 AI 消息
  - 自动滚动到最新消息
  - 支持向上滚动查看历史
- **验收标准**:
  - 消息顺序正确
  - 新消息自动滚动到底部
  - 滚动流畅，无卡顿

### 2.2 会话管理 (FR-002)

#### 2.2.1 会话列表 (FR-002-001)
- **描述**: 侧边栏显示所有会话列表
- **优先级**: P0（必须）
- **功能点**:
  - 显示会话标题（基于首条消息）
  - 显示最后活跃时间
  - 支持会话切换
  - 按日期分组（今天/昨天/7 天内/更早）
- **验收标准**:
  - 会话列表正确显示
  - 切换会话无延迟
  - 日期分组准确

#### 2.2.2 新建会话 (FR-002-002)
- **描述**: 用户可以创建新的对话会话
- **优先级**: P0（必须）
- **功能点**:
  - 点击"新建对话"按钮
  - 自动生成会话 ID
  - 切换到新会话
- **验收标准**:
  - 新会话正确创建
  - 会话 ID 唯一
  - 切换到新会话并清空输入

#### 2.2.3 删除会话 (FR-002-003)
- **描述**: 用户可以删除不需要的会话
- **优先级**: P1（重要）
- **功能点**:
  - 悬停显示删除按钮
  - 点击后弹出确认对话框
  - 删除后切换到其他会话
- **验收标准**:
  - 删除操作需要确认
  - 删除后会话不可恢复
  - 切换到有效会话

#### 2.2.4 重命名会话 (FR-002-004)
- **描述**: 用户可以自定义会话标题
- **优先级**: P2（可选）
- **功能点**:
  - 点击标题进入编辑模式
  - 输入新标题

- **验收标准**:
  - 标题编辑流畅
  - 保存后立即生效

## 5. 边界条件

### 5.1 输入限制

| 项目 | 限制 | 处理方式 |
|------|------|----------|
| **单条消息长度** | 最大 4000 字符 | 超出时显示警告，禁用发送 |
| **会话数量** | 最大 100 个 | 超出时提示删除旧会话 |
| **消息数量/会话** | 最大 1000 条 | 超出时归档旧消息 |
| **文件上传** | 暂不支持 | 未来版本实现 |

### 5.2 错误场景

| 场景 | 处理方式 |
|------|----------|
| **网络断开** | 显示"网络连接已断开"提示，支持重试 |
| **API 超时** | 5 秒后显示超时提示，允许重新发送 |
| **服务器错误** | 显示友好的错误信息，提供错误代码 |
| **无效输入** | 实时验证，显示具体错误提示 |
| **会话不存在** | 自动创建新会话或跳转到最近会话 |

### 5.3 极端情况

| 情况 | 预期行为 |
|------|----------|
| **非常长的消息** | 虚拟滚动，分段渲染 |
| **大量代码块** | 按需加载语法高亮 |
| **网络抖动** | 断点续传，避免重复请求 |
| **浏览器崩溃** | localStorage 保存草稿，恢复会话 |

## 6. 数据模型

### 6.1 会话 (Session)

```typescript
interface Session {
  id: string;                // 会话唯一标识
  title: string;             // 会话标题
  createdAt: Date;           // 创建时间
  updatedAt: Date;           // 最后更新时间
  messageCount: number;      // 消息数量
  metadata?: {
    tags?: string[];         // 标签
    archived?: boolean;      // 是否归档
    pinned?: boolean;        // 是否置顶
  };
}
```

### 6.2 消息 (Message)

```typescript
interface Message {
  id: string;                // 消息唯一标识
  sessionId: string;         // 所属会话
  role: 'user' | 'assistant'; // 发送者角色
  content: string;           // 消息内容（支持 Markdown）
  createdAt: Date;           // 发送时间
  status: 'sending' | 'sent' | 'error'; // 发送状态
  metadata?: {
    tokenCount?: number;     // Token 数量
    model?: string;          // 使用的模型
    regenerated?: boolean;   // 是否重新生成
  };
}
```

### 6.3 用户偏好 (UserPreferences)

```typescript
interface UserPreferences {
  theme: 'light' | 'dark' | 'system'; // 主题偏好
  fontSize: 'small' | 'medium' | 'large'; // 字体大小
  reducedMotion: boolean;    // 减少动画
  sidebarCollapsed: boolean; // 侧边栏折叠状态
  streamResponse: boolean;   // 是否使用流式响应
}
```

## 7. API 规范

### 7.1 发送消息

```typescript
POST /api/v1/chat/

Request:
{
  session_id: string;
  message: string;
  stream: boolean;
}

Response (SSE):
event: message
data: {"content": "逐字返回的内容"}

event: done
data: {"session_id": "xxx", "message_id": "xxx"}
```

### 7.2 获取会话列表

```typescript
GET /api/v1/sessions

Response:
{
  sessions: Session[];
  total: number;
}
```

### 7.3 获取消息历史

```typescript
GET /api/v1/chat/history/{session_id}

Response:
{
  messages: Message[];
  hasMore: boolean;
  cursor?: string;
}
```
