#### 1.2.2 状态管理架构

```typescript
// Zustand Store 结构
interface AIStore {
  // 会话状态
  sessions: Session[];
  currentSessionId: string | null;
  
  // 消息状态
  messages: Record<string, Message[]>;
  
  // UI 状态
  isLoading: boolean;
  isStreaming: boolean;
  error: string | null;
  
  // 操作方法
  createSession: () => void;
  deleteSession: (id: string) => void;
  switchSession: (id: string) => void;
  sendMessage: (content: string) => void;
  addMessage: (message: Message) => void;
}
```

## 2. 技术选型

### 2.1 核心技术栈

| 技术 | 版本 | 选择理由 | 替代方案 |
|------|------|---------|----------|
| **Next.js** | 15.5.5 | SSR/SSG 支持，路由简单，性能优秀 | Remix, Gatsby |
| **React** | 19.1.0 | 最新特性，生态丰富，社区活跃 | Vue, Svelte |
| **TypeScript** | 5.3+ | 类型安全，IDE 支持好，减少错误 | JavaScript |
| **TailwindCSS** | 4.x | 快速开发，类型安全，体积小 | CSS Modules, Styled Components |
| **Framer Motion** | 11.18.2 | 声明式动画，性能好，易用 | React Spring, GSAP |
| **Zustand** | 5.0.8 | 轻量级，API 简单，TypeScript 友好 | Redux, Jotai |

### 2.2 辅助工具库

| 工具 | 用途 | 选择理由 |
|------|------|---------|
| **CVA** | 变体管理 | 类型安全，与 TailwindCSS 集成好 |
| **clsx** | 类名合并 | 简单高效，体积小 |
| **next-themes** | 主题切换 | 无闪烁，SSR 支持 |
| **react-markdown** | Markdown 渲染 | 插件丰富，易扩展 |
| **remark-gfm** | GitHub 风格 Markdown | 支持表格、删除线等 |
| **lucide-react** | 图标库 | 一致性好，体积小，可定制 |

### 2.3 开发工具

| 工具 | 用途 |
|------|------|
| **pnpm** | 包管理器（快速，节省空间） |
| **Turbopack** | 构建工具（Next.js 15 内置） |
| **ESLint** | 代码检查 |
| **Prettier** | 代码格式化 |
| **TypeScript** | 类型检查 |

### 2.4 技术决策记录

#### 为什么选择 Next.js 而不是 CRA？
- ✅ 内置 SSR/SSG，SEO 友好
- ✅ 文件路由系统简单
- ✅ 性能优化开箱即用
- ✅ Vercel 部署方便

#### 为什么选择 Zustand 而不是 Redux？
- ✅ API 更简单，学习曲线低
- ✅ 无需 Provider 包裹
- ✅ TypeScript 支持更好
- ✅ 包体积更小（~1KB）

#### 为什么选择 TailwindCSS 而不是 CSS-in-JS？
- ✅ 性能更好（编译时处理）
- ✅ 类型安全（v4 原生支持）
- ✅ 开发效率高
- ✅ 生产体积小

| 风险 | 影响 | 概率 | 缓解措施 |
