# 📝 Markdown 渲染规则指南

**项目**: Ivan_HappyWoods Frontend  
**组件**: `MarkdownMessage` (使用 `react-markdown` + `remark-gfm`)  
**更新日期**: 2025-10-29

---

## 🎯 概述

前端使用 **react-markdown** 库渲染 Markdown，支持 **GitHub Flavored Markdown (GFM)** 扩展语法。

### 核心依赖
```json
{
  "react-markdown": "^9.x",
  "remark-gfm": "^4.x"
}
```

---

## ✅ 支持的 Markdown 语法

### 1. 标题 (Headings)

**后端应返回**:
```markdown
# 一级标题
## 二级标题
### 三级标题
```

**渲染效果**:
- `#` → 2xl 字体，粗体，上下间距
- `##` → xl 字体，半粗体，上下间距
- `###` → lg 字体，半粗体，上下间距

**注意事项**:
- ✅ 标题后必须有空行
- ✅ 标题前的 `#` 和文字之间要有空格
- ❌ 不支持 `====` 和 `----` 风格的标题

---

### 2. 段落 (Paragraphs)

**后端应返回**:
```markdown
这是第一段文字。

这是第二段文字，段落之间用空行分隔。
```

**渲染效果**:
- 每个段落之间有 `mb-4` 间距
- 行高 `leading-relaxed` (1.625)
- 最后一段无底部间距

**注意事项**:
- ✅ 段落之间用**一个空行**分隔
- ✅ 段落内换行用 `\n` 或 `  \n` (两个空格+换行)
- ❌ 单个换行符不会产生新段落

---

### 3. 列表 (Lists)

#### 3.1 无序列表 (推荐格式)

**后端应返回** (方式1 - 推荐):
```markdown
- 第一项
- 第二项
- 第三项
```

**后端应返回** (方式2):
```markdown
* 第一项
* 第二项
* 第三项
```

**渲染效果**:
```
• 第一项
• 第二项
• 第三项
```

#### 3.2 有序列表

**后端应返回**:
```markdown
1. 第一项
2. 第二项
3. 第三项
```

**渲染效果**:
```
1. 第一项
2. 第二项
3. 第三项
```

#### 3.3 嵌套列表

**后端应返回**:
```markdown
如需我:

- 继续追踪并每小时更新最新报道；
- 汇总不同消息来源的信息并排除的信息；
- 将上述信息翻译成英文并列出原始链接供分享；

告诉我你想要哪一种，我会立即为你执行。✅
```

**关键规则**:
1. ✅ 列表项使用 `-` 或 `*` 开头
2. ✅ 列表项后必须有空格: `- 内容` (不是 `-内容`)
3. ✅ 列表项以分号 `;` 结尾
4. ✅ 最后一项可以没有分号
5. ✅ 列表前后加空行
6. ✅ 每个列表项独占一行

**嵌套列表格式**:
```markdown
- 主项目 1
  - 子项目 1.1
  - 子项目 1.2
- 主项目 2
  - 子项目 2.1
```

**注意**:
- 嵌套列表需要 **2个空格或1个Tab** 缩进
- 当前配置: `list-outside` + `pl-6` (左侧缩进 1.5rem)

---

### 4. 代码 (Code)

#### 4.1 行内代码

**后端应返回**:
```markdown
这是 `行内代码` 示例。
```

**渲染效果**:
```
这是 行内代码 示例。(橙色背景)
```

#### 4.2 代码块

**后端应返回**:
````markdown
```python
def hello():
    print("Hello World")
```
````

**渲染效果**:
- 带语言标签的代码块 (顶部显示 "PYTHON")
- 复制按钮 (右上角)
- 语法高亮样式 (需要配合 CSS)
- 深色背景 `bg-[var(--surface-base)]`

**支持的语言标识**:
```
python, javascript, typescript, jsx, tsx, 
bash, shell, json, yaml, html, css, 
java, c, cpp, go, rust, sql, markdown
```

**注意事项**:
- ✅ 代码块前后必须有空行
- ✅ 语言标识紧跟 ` ``` ` 后面
- ✅ 代码内容保持原始缩进
- ❌ 不要在代码块内再嵌套 Markdown

---

### 5. 引用 (Blockquotes)

**后端应返回**:
```markdown
> 这是一段引用文字。
> 可以有多行。
```

**渲染效果**:
```
┃ 这是一段引用文字。
┃ 可以有多行。
(左侧琥珀色竖线 + 斜体)
```

---

### 6. 表格 (Tables)

**后端应返回**:
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据1 | 数据2 | 数据3 |
| 数据4 | 数据5 | 数据6 |
```

**渲染效果**:
- 带边框的表格
- 表头深色背景
- 横向滚动 (overflow-x-auto)

**注意事项**:
- ✅ 表格前后要有空行
- ✅ 使用 `|` 分隔列
- ✅ 第二行用 `---` 分隔表头
- ✅ 对齐方式: `:-` 左对齐, `:-:` 居中, `-:` 右对齐

---

### 7. 链接 (Links)

**后端应返回**:
```markdown
[链接文字](https://example.com)
```

**渲染效果**:
- 琥珀色文字
- 悬停下划线
- 自动打开新标签 (`target="_blank"`)

---

### 8. 强调 (Emphasis)

**后端应返回**:
```markdown
这是 **粗体** 文字。
这是 *斜体* 文字。
这是 ***粗斜体*** 文字。
```

**渲染效果**:
- `**文字**` → 粗体
- `*文字*` → 斜体 (灰色)
- `***文字***` → 粗斜体

---

### 9. 水平线 (Horizontal Rule)

**后端应返回**:
```markdown
---
```

**渲染效果**:
```
━━━━━━━━━━━━━━━━━━━━
(灰色分隔线)
```

---

### 10. 任务列表 (Task Lists) - GFM 扩展

**后端应返回**:
```markdown
- [ ] 未完成任务
- [x] 已完成任务
```

**渲染效果**:
```
☐ 未完成任务
☑ 已完成任务
```

---

### 11. 删除线 (Strikethrough) - GFM 扩展

**后端应返回**:
```markdown

```

**渲染效果**:
```
删除的文字 (带删除线)
```

## ❌ 不支持的语法

以下语法 **react-markdown** 默认不支持或需要额外插件:

1. ❌ **HTML 标签** (出于安全考虑)
   ```markdown
   <div>HTML 内容</div>  ❌ 不渲染
   ```

2. ❌ **LaTeX 数学公式** (需要 remark-math 插件)
   ```markdown
   $E = mc^2$  ❌ 不渲染
   ```

3. ❌ **脚注** (Footnotes)
   ```markdown
   文字[^1]  ❌ 不支持
   [^1]: 脚注内容
   ```

4. ❌ **定义列表** (Definition Lists)
   ```markdown
   术语
   : 定义  ❌ 不支持
   ```

5. ❌ **表情符号简码** (需要 remark-emoji 插件)
   ```markdown
   :smile: :heart:  ❌ 不会转换为 😊 ❤️
   ```

6. ❌ **图片** (当前未配置)
   ```markdown
   ![图片](url)  ❌ 显示但可能样式不正确
   ```

## 🎨 样式规则

### 颜色变量
```css
--text-primary: 主要文字颜色
--text-secondary: 次要文字颜色 (引用、斜体)
--text-tertiary: 三级文字颜色
--interactive-primary: 交互色 (链接、代码背景) - #E4B16B (琥珀色)
--surface-base: 基础背景
--surface-elevated: 卡片背景
--border-subtle: 边框颜色
```

### 间距系统
- 标题上下间距: `mb-4 mt-6` (h1), `mb-3 mt-5` (h2), `mb-2 mt-4` (h3)
- 段落间距: `mb-4`
- 列表间距: `space-y-1` (列表项) + `mb-4` (整个列表)
- 代码块间距: `mb-4`

## 🐛 常见问题

### Q1: 列表项显示不正确
**问题**: 列表项没有项目符号  
**原因**: 列表项前缺少空格  
**解决**: 
```markdown
❌ -列表项  (缺少空格)
✅ - 列表项  (正确格式)
```

### Q2: 代码块不高亮
**问题**: 代码块没有语言标签  
**原因**: 未指定语言  
**解决**:
````markdown
❌ 
```
代码
```

✅ 
```python
代码
```
````

### Q3: 段落没有换行
**问题**: 换行无效  
**原因**: 单个换行符不产生新段落  
**解决**:
```markdown
❌ 
段落1
段落2

✅ 
段落1

段落2
```
