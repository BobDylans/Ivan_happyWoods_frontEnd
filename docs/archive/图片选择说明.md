## 🎯 如何替换图片

只需修改 `client/src/components/home/hero-section.tsx`：

```tsx
const images = [
  {
    url: 'https://images.pexels.com/photos/你的图片ID/...?auto=compress&cs=tinysrgb&w=1920',
    alt: '图片描述',
  },
  // ... 更多图片
];
```

**获取 Pexels 图片 URL**:
1. 访问 Pexels.com
2. 找到喜欢的图片
3. 点击 "Download" 旁边的箭头
4. 选择 "Large (1920px)"
5. 复制 URL
6. 添加参数 `?auto=compress&cs=tinysrgb&w=1920`

---

## 📐 图片优化参数说明

我们在 URL 中添加了优化参数：

```
?auto=compress&cs=tinysrgb&w=1920
```

**参数含义**:
- `auto=compress` - 自动压缩（减少 60-70% 大小）
- `cs=tinysrgb` - tinysRGB 色彩空间（更小）
- `w=1920` - 宽度 1920px（适合大屏幕）

**移动端优化**:
如果需要针对移动端，可以使用：
```
?auto=compress&cs=tinysrgb&w=750  // 移动端
```
