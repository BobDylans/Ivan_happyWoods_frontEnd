### ✅ 2. 错误处理增强

#### 2.1 SSE Hook 增强
**文件**: `client/src/hooks/use-sse-stream.ts`

**新增功能**:
- ⏱️ **超时检测**: 默认 30 秒超时，可配置
- 🔄 **自动重试**: 最多重试 3 次，指数退避 (1s → 2s → 3s)
- 🏷️ **错误分类**: 7 种错误类型
  - `timeout` - 请求超时
  - `network` - 网络连接失败
  - `auth` - 身份验证失败 (401/403)
  - `notfound` - 接口不存在 (404)
  - `server` - 服务器错误 (500/502/503)
  - `canceled` - 用户取消
  - `unknown` - 未知错误
- 💬 **友好错误消息**: 每种错误都有详细的中文提示和解决方案
- 📊 **重试计数**: 显示当前重试次数

**配置接口**:
```typescript
interface SSEStreamConfig {
  timeout?: number;      // 超时时间 (默认 30000ms)
  maxRetries?: number;   // 最大重试次数 (默认 3)
  retryDelay?: number;   // 重试延迟 (默认 1000ms)
}
```

#### 2.2 UI 错误展示
**文件**: `client/src/components/ai/ai-chat-state.tsx`

**新增内容**:
- 🔴 **错误消息边框**: 红色边框标识错误消息
- 🔄 **重试按钮**: 带重试次数显示 "重试 (1/3)"
- 🏷️ **错误类型显示**: 显示错误分类
