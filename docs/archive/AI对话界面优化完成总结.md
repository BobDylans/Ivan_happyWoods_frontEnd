## 📈 性能优化

### 1. 状态管理
- 使用 `Set` 数据结构存储点赞/点踩（O(1) 查找）
- 避免不必要的重渲染

### 2. 动画性能
- 使用 CSS `transform` 而非 `width/height`
- Framer Motion 自动优化动画性能
- 骨架屏使用 `opacity` 动画（GPU 加速）

### 3. 内存优化
- 复制提示自动清除（2 秒后）
- 使用 `useCallback` 避免函数重复创建
