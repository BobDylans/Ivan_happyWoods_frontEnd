# 骨架屏颜色优化总结

## 📅 更新时间
2025年10月29日

## 🎯 优化目标
将骨架屏的颜色和文字对比度调整为与实际消息内容保持一致，避免视觉上的突兀感。

## ✨ 主要改动

### 1. **ThinkingIndicator（思考指示器）**

#### 优化前：
- 使用琥珀色渐变背景：`from-amber-50 to-orange-50`
- 文字颜色：`text-amber-700` / `text-amber-300`（深色模式）
- 图标颜色：`text-amber-600` / `text-amber-400`
- 强调感较强，与实际消息风格差异大

#### 优化后：
```tsx
<div className="bg-[var(--surface-elevated)] border border-[var(--border-subtle)]">
  <Brain className="text-[var(--text-secondary)]" />
  <span className="text-[var(--text-secondary)]">正在思考...</span>
  <div className="bg-[var(--text-tertiary)]">...</div>
  <Sparkles className="text-[var(--text-tertiary)]" />
</div>
```

**改进效果：**
- ✅ 使用设计系统的颜色变量
- ✅ 背景色与实际消息框一致：`surface-elevated`（白色/浅色）
- ✅ 文字使用次要文本颜色：`text-secondary`（灰色系）
- ✅ 辅助元素使用三级文本颜色：`text-tertiary`（更浅的灰色）
- ✅ 去除 "AI" 前缀，简化为"正在思考..."
- ✅ 图标尺寸从 `w-5 h-5` 减小到 `w-4 h-4`，更精致

---

### 2. **MessageSkeleton（消息骨架屏）**

#### 优化前：
- 消息框背景：琥珀色渐变 `from-amber-50 to-orange-50`
- 文字行背景：`bg-amber-200`
- 边框：`border-amber-200/50`

#### 优化后：
```tsx
<div className="bg-[var(--surface-elevated)] border border-[var(--border-subtle)]">
  <div className="bg-[var(--border-subtle)] h-4 rounded" />
</div>
```

**改进效果：**
- ✅ 消息框背景改为标准白色/浅色
- ✅ 文字行使用边框颜色 `border-subtle`，更接近实际文字的对比度
- ✅ 透明度动画：`opacity: [0.3, 0.6, 0.3]` 更柔和
- ✅ 文字行高度从 `h-3` 增加到 `h-4`，更接近实际文字

### 6. **基础 Skeleton 组件**

#### 优化前：
```tsx
'bg-gradient-to-r from-amber-50 to-orange-50'
'border border-amber-200/50'
opacity: [0.5, 0.8, 0.5]
```

#### 优化后：
```tsx
'bg-[var(--border-subtle)]'
opacity: [0.3, 0.6, 0.3]
```

**改进效果：**
- ✅ 简化样式，去除渐变和边框
- ✅ 降低动画对比度，更柔和
- ✅ 与实际内容的灰色文字行更匹配

## 🎨 颜色对比表

| 元素 | 优化前 | 优化后 | 说明 |
|------|--------|--------|------|
| **思考文字** | `text-amber-700` | `text-[var(--text-secondary)]` | 灰色系，与实际消息一致 |
| **消息框背景** | `from-amber-50 to-orange-50` | `bg-[var(--surface-elevated)]` | 白色/浅色，统一风格 |
| **文字行** | `bg-amber-200` | `bg-[var(--border-subtle)]` | 低对比度灰色 |
| **辅助图标** | `text-amber-600` | `text-[var(--text-tertiary)]` | 更浅的灰色 |
| **动画透明度** | `0.5 → 0.8` | `0.3 → 0.6` | 降低对比度 |

---

## 📊 设计系统颜色变量说明

```css
/* 使用的颜色变量 */
--surface-base: #FDFCF9;           /* 页面基础背景 */
--surface-elevated: #FFFFFF;       /* 卡片/消息框背景 */
--text-primary: #1A1916;           /* 主要文字（黑色） */
--text-secondary: #656259;         /* 次要文字（深灰） */
--text-tertiary: #C9C5B8;          /* 三级文字（浅灰） */
--border-subtle: #E8E5DD;          /* 边框/分隔线 */
```
