# ⚡ 快速启动指南

## ❌ 错误的方式

```bash
# 在 frontEnd 目录下运行（会报错！）
D:\Projects\ivanHappyWoods\frontEnd> pnpm dev
# ❌ Error: No package.json found
```

---

## ✅ 正确的方式

### 方式 1: 使用启动脚本（最简单）

```bash
# 在 frontEnd 目录下，双击或运行：
.\start-dev.bat
```

### 方式 2: 手动进入目录

```bash
# 步骤 1: 进入 client 目录
cd client

# 步骤 2: 启动开发服务器
pnpm dev
```

### 方式 3: 一行命令

```bash
cd client && pnpm dev
```

---

## 📍 目录说明

```
frontEnd/                 ← 你现在在这里
├── client/               ← package.json 在这里！
│   ├── package.json      ← 项目配置文件
│   ├── src/              ← 源代码
│   └── node_modules/     ← 依赖包
└── start-dev.bat         ← 快速启动脚本
```

---

## 🎯 为什么会这样？

重构后，项目结构变成了：
- `frontEnd/` - 项目根目录（没有 package.json）
- `frontEnd/client/` - 前端应用目录（有 package.json）

所以运行 `pnpm dev` 必须在 `client` 目录下。

---

## 🚀 启动步骤（详细）

### Windows PowerShell/CMD:

```powershell
# 当前位置：frontEnd 目录
PS D:\Projects\ivanHappyWoods\frontEnd>

# 步骤 1: 进入 client
cd client

# 步骤 2: 验证文件存在
dir package.json
# 应该显示 package.json 文件

# 步骤 3: 启动服务器
pnpm dev
```

### 启动成功后，你会看到：

```
  ▲ Next.js 15.5.5
  - Local:        http://localhost:3000
  - Environments: .env.local

 ✓ Ready in 2.3s
```

## 💡 小贴士

1. **推荐使用启动脚本**: 双击 `start-dev.bat` 即可
2. **首次启动可能较慢**: Turbopack 需要编译，等待 2-5 秒
3. **热更新**: 修改代码后会自动刷新浏览器
4. **停止服务器**: 按 `Ctrl + C`

---

## ❓ 还是不行？

### 检查清单：

- [ ] 确认在 `client` 目录下
- [ ] 确认 `package.json` 存在
- [ ] 确认已运行 `pnpm install`
- [ ] 确认端口 3000 未被占用
- [ ] 确认 Node.js 版本 >= 20

### 重新安装依赖：

```bash
cd client
rm -rf node_modules
rm pnpm-lock.yaml
pnpm install
pnpm dev
```
