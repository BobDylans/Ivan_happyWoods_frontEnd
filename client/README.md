# 🌿 Ivan_HappyWoods Design System

A warm, natural, and intelligent design system built with Next.js, TailwindCSS, and Framer Motion.

## ✨ Features

- 🎨 **Warm Design Language** - Natural tones and gentle animations
- 🌓 **Dark Mode Support** - Seamless theme switching with no flash
- ♿ **WCAG AAA Accessibility** - 7:1 minimum contrast ratio
- 🎬 **Rich Animation Library** - 20+ animation presets
- 🔧 **Type-Safe Components** - CVA-powered variant management
- 📱 **Responsive Design** - Mobile-first approach

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build
```

## 📚 Documentation

See `/specs/001-design-specification-ivan/` for comprehensive design documentation.

## 🎨 Component Library

- **Button** - 6 variants with spring animations
- **Card** - Elevated, outlined, and default styles
- **Logo** - With optional breathing glow effect
- **Theme Toggle** - Smooth light/dark mode switching

## 📦 Tech Stack

- Next.js 15.5.5
- React 19.1.0
- TailwindCSS 4.x
- Framer Motion 11.18.2
- TypeScript 5.x
